Вопросы загружаются из файла questions.txt

Формат файла questions.txt должен быть такой (пример):

9. Кто из античных философов своим учением определил «линию материализма» в философии?
[ ] Платон
[ ] Пифагор
[x] Демокрит
[ ] Протагор
[ ] Сократ

10. Кто из античных философов своим учением определил «линию идеализма» в философии?
[x] Платон
[ ] Аристотель
[ ] Гераклит
[ ] Эпикур
[ ] Цицирон

Вариант считается правильным если внутри квадратных скобок стоит x или русская х. Поддерживаются несколько правильных ответов (несколько пометок [x]).
